# Privacy

rea-casebook is a Claude Code mod that runs on your machine. It has no server and collects nothing for its author: it sends nothing to me or to anyone else.

- **What it keeps.** The casebook of each session lives in the Claude Code session and in a journal under `~/.rea-casebook/` in your home folder, named after the Claude Code session id. The journal holds the session id, its counters and, once you publish the page, that artifact's URL; the binary rea opened, named by its file name and SHA-256, never by its local path; and, for each Evidence record, its `evidence_id`, operation, confidence, authority and up to two of the call's parameters, never rea's results themselves. A rea tool that takes a path, such as `inspect_pe_resources` or the Android tools, can put that path in those parameters. The open unknowns and the findings are kept as rea and the model wrote them. The Markdown export and the artifact page go to the same folder. Nothing is ever written into your project.
- **What it reads.** The results of the rea calls your agent already made, a rea result that Claude Code saved to a file because it was too large, the Claude Code session id, and the environment variable `USERPROFILE` or `HOME`, only to find your home folder. It reads no credentials: no token, key or password.
- **What leaves your machine.** Only the casebook page, and only when you ask Claude to publish the page that `/casebook artifact` writes: Claude Code's Artifact tool publishes it to your own claude.ai account as a private artifact, under the terms of that service. The mod itself calls no tool, submits no prompt and has no network access. The page names the binary by file name, never by its local path. It also shows the binary's SHA-256, the findings, the open unknowns and each call's parameters as rea and the model wrote them: check the page before you share it. You decide whether to share it.
- **Retention.** The mod never deletes or rotates these files: they stay until you delete them. A published artifact stays in your claude.ai account under Anthropic's terms and privacy policy until you delete it.
- **Deleting your data.** Delete the `~/.rea-casebook/` folder and any artifact you published from your claude.ai gallery.

Questions: open an issue at https://github.com/pablodiazjorge/rea-casebook/issues.
